# CLAUDE.md — academic/sql

SQL scripts and query sessions written while studying with this environment.

## Contents

- `carlos-database.session.sql` — a SQLTools query-session scratch file. It's auto-generated by the SQLTools extension whenever a new query editor tab is opened against a connection (in this case, the `carlos-database` SQLTools connection — see `../../.vscode/CLAUDE.md`). It started out empty, at the repo root, and was moved here in two steps at the user's request: first into `academic/` generally, then into its own `academic/sql/` subfolder ("deverá ter um pasta própria").

## Note on future SQLTools session files

New query tabs opened in SQLTools inside the devcontainer will keep generating similarly-named `.session.sql` files at the workspace root by default. Move them here to keep the repo root clean, consistent with how the first one was handled.
